An experiment in procedural world generation. Still early-days, currently shapes some noise-generated elevation, making something that looks like this:

[Example island](example.png)

The goal is to slowly reach something similar to Dwarf Fortress's world generation.

Strongly inspired by [Cumberland Games's "Medieval Demographics Made Easy"](https://gamingballistic.com/wp-content/uploads/2018/11/Medieval-Demographics-Made-Easy-1.pdf)
 and the venerable RedBlobGames guides on [hexagonal grids](https://www.redblobgames.com/grids/hexagons/) and [making maps with noise](https://www.redblobgames.com/maps/terrain-from-noise/).
